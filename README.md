# ShareCapsule Research

ShareCapsule Research is a community-oriented workspace for turning expertise into credible research, applied learning, public contribution, and reusable evidence.

The first product surface is **Impact Commons**. It extends the opportunity-discovery model used by professional-brand platforms with research integrity, skill development, peer learning, and community impact verification.

## Current capabilities

- Explainable opportunity matching for speaking, judging, peer review, research, and media
- Evidence-led proposal and abstract drafting
- Research claim ledger with source-strength and gap analysis
- Applied skill sprints that end in reviewable artifacts
- Community contribution projects and impact tracking
- Evidence vault for publications, talks, professional profiles, and expert review
- Browser-local draft and progress persistence
- Exportable evidence summary

## Run locally

No build step is required.

```bash
python3 -m http.server 4173 --directory dist
```

Open `http://localhost:4173`.

## Product principles

1. Genuine expertise before credential collection.
2. Claims remain separate from evidence and assumptions.
3. AI structures and challenges work; the human remains the author.
4. Learning must produce a useful, reviewable artifact.
5. Community impact requires beneficiary or peer verification.
6. Immigration evidence organization never replaces legal advice.

## Status

This repository contains the functional front-end MVP. The next phase adds authentication, persistent storage, verified opportunity ingestion, citation-backed AI, collaborative review, and moderation.
